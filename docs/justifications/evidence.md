# Ver o descargar una evidencia

1. Abre **Justificaciones** o **Gestión de justificaciones** y entra al detalle de la solicitud.
2. En **Evidencia**, selecciona **Ver evidencia** para abrir un PDF, JPG o PNG en una pestaña nueva.
3. Para guardar una copia, selecciona **Descargar evidencia**. Esta opción también aparece cuando el formato solo admite descarga.

Si tu navegador bloquea la pestaña nueva, permite abrirla para MARSYS o usa **Descargar evidencia**. Si el enlace caduca, vuelve al detalle y selecciona la acción otra vez.

Las opciones están disponibles para las cuentas que ya tienen permiso de acceso a la evidencia.
